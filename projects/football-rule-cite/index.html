Football Rule Cite

A local retrieval tool for explaining a stated football decision with IFAB law excerpts.

Open static sample ↗GitHub repository ↗

Problem & motivation

A football explanation is more useful when the relevant source passage can be inspected beside it.

How it works

The Python pipeline downloads and indexes the IFAB source, retrieves page-labelled passages, and asks a local Ollama model to explain a stated call. The hosted page is a static sample; new answers require the local server.

Evidence & limits

Both saved July 8 runs passed 10/10 seed scenarios for expected-law coverage and required uncertainty presence. Extra law numbers did not fail the scorer. These results do not establish decision correctness; model digests and PDF hashes were not captured.

What I learned & next steps

I learned that a passing retrieval check needs a precise definition. I would add expert-reviewed grounding checks and pin runtime metadata before making broader claims.
